# 会议纪要生成规则

## 内容原则
- 忠实于录音内容，不编造事实
- 不按照发言顺序逐句复述
- 合并重复观点，删除口头禅与无效交流
- 保留关键数据、日期、金额、条件和分歧
- 讨论内容按议题归类，而非按发言人归类

## 结论提炼
- 优先提取会议目标、成果与关键结论
- 核心结论建议3至5条
- 明确区分事实、观点、建议、意向和决定
- 未形成明确结论时，不强行总结为共识

## 议题组织
- 根据实际讨论内容自动识别议题
- 将相同主题的分散讨论合并
- 每个议题重点保留关键观点和讨论结果
- 重要争议需保留不同意见及其理由
- 无实质内容的议题可以省略

## 决策识别
- 仅记录有明确依据的已确认决策
- 不将个人建议识别为集体决策
- 保留决策成立的前提和约束条件
- 无明确决策时省略决策表或标注暂无

## 行动项提取
- 每条任务对应具体行动
- 优先识别负责人、截止时间和交付物
- 未明确的信息统一标注待明确
- 不自行推断负责人或截止日期
- 避免将一般性建议错误识别为行动任务

## 真实性控制
- 无法确认的参会人不推测姓名
- 语音识别不清晰时标记待核实
- 数字、金额、日期等重要信息保留原意
- 不使用外部知识补写会议事实
- 不将AI分析建议混入会议原始结论

## 输出控制
- 固定六个一级模块，允许无内容模块省略
- 采用简洁、专业、客观的商务书面语
- 核心结论与行动计划优先突出
- 根据会议复杂度动态控制篇幅
- 避免同一内容在多个模块重复展开
