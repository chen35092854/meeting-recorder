# 会议纪要生成 Prompt 约束（可编辑）

本目录是**会议纪要 LLM 生成的唯一约束源**。修改其中的文件即可调整纪要生成行为，无需改代码。

## 文件说明

| 文件 | 作用 | 修改后影响 |
|---|---|---|
| `system_prompt.md` | 生成规则（内容原则/结论提炼/议题组织/决策识别/行动项提取/真实性控制/输出控制） | 约束摘要、议题、决策、任务等如何提炼 |
| `template.md` | 纪要 Markdown 骨架（六个一级模块 + 文末转写全文链接） | 决定最终文档结构；**文末“📎 转写全文”链接请保留**（程序以此定位追加） |
| `length_guide.md` | 按会议类型推荐的纪要长度 | 引导不同复杂度会议的字数 |

## 生效方式

- **GUI 结束会议自动生成**（`app/summarize.py`）：每次生成时实时读取本目录文件；
- **对话兜底通道**（skill 场景二）：同样读取本目录文件生成。

读取顺序：`system_prompt.md` + `template.md` + `length_guide.md` 拼接为系统提示词。
任一文件缺失时程序回退到内置默认，**不会报错**（但会绕开你的自定义，请保持三个文件完整）。

## 注意事项

- 文件需为 UTF-8 纯文本；保持一级标题 `#` 开头即可被正常识别。
- 若删除 `template.md` 中的「转写全文」链接，保存时会自动追加，避免纪要缺失转写入口。
